# Cost and platform limitations

Only Databricks Free Edition serverless/Unity Catalog capabilities, local Python, and existing open-source tooling are in scope. No paid cloud service, external object store, GPU, subscription, paid API, or billing upgrade was provisioned.

Free Edition availability has not been verified here. Lakeflow, SQL warehouse, AI/BI Dashboard, volume creation, and quotas are therefore platform-dependent `NOT_EXECUTED` items. Local pytest validation is blocked because the recreated environment cannot resolve locked packages; this is not a product or cloud result. No performance/cost measurement is claimed.
